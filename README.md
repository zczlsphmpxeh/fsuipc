## Overview

FSUIPC (Flight Simulator Universal Inter-Process Communication) is the industry-standard middleware layer for MSFS 2020/2024, MSFS 2004, FSX, and Prepar3D, providing external applications and hardware interfaces access to thousands of simulator variables and events via a documented offset system. It is required by hundreds of popular add-ons including GSX, SPAD.neXt, Axis and Ohs, and ProSimUtils.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FSUIPC** delivers the features you need in a clean, intuitive package.

> Official website: [fsuipc.com](https://fsuipc.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **Universal Variable Access** | Thousands of simulator variables exposed via documented offsets |
| **Hardware Integration** | Bridge for SPAD.neXt, Axis and Ohs, and custom hardware controllers |
| **Add-On Prerequisite** | Required middleware for GSX, ProSimUtils, and hundreds of popular tools |
| **Multi-Sim Support** | Covers MSFS 2020/2024, FSX, MSFS 2004, and Prepar3D |
